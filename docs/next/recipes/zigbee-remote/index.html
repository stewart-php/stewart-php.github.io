Zigbee remote over MQTT

Reads the button presses of a Zigbee remote straight from Zigbee2MQTT, and turns a light on, off, brighter or dimmer. No Home Assistant automation is involved, and presses are handled as soon as they arrive.

You need Zigbee2MQTT and an MQTT server that Stewart is connected to.

How it works

Section titled “How it works”
  • Zigbee2MQTT publishes each press on zigbee2mqtt/<name>/action, with the action as the payload.
  • A match turns each action into a service and its data. Unknown actions are ignored.
  • brightness_step_pct changes the brightness relative to where it is.

Make it yours

Section titled “Make it yours”
  • Find your remote’s actions: watch zigbee2mqtt/<name>/action with mosquitto_sub, and press each button.
  • Long presses: many remotes send brightness_move_up and brightness_stop; start a runEvery() on the first and cancel it on the second.
